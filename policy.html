Word Rush Privacy Policy

1. Information Collected

Word Rush may collect and store the following information for game progression, match synchronization, fraud prevention, and service improvement.

  • Randomly generated playerId
  • room id / room code
  • Room information for friend matches and random matches
  • Entered words
  • Scores
  • Match event history
  • Creation and update timestamps
  • Information stored in the browser's localStorage

At present, this service generally does not collect information that directly identifies individuals, such as names, email addresses, or login information.

2. Purpose of Use

Collected information is used for the following purposes.

  • Managing game progression
  • Synchronizing friend matches and random matches
  • Displaying scores and results
  • Preventing fraud, spam, and data tampering
  • Improving the service, checking operation, and investigating issues
  • Reference for future feature improvements

3. Use of localStorage

This service stores a random playerId in the browser's localStorage in order to identify the same device.

The main stored item is as follows.

  • wordRushPlayerId

This playerId is used to identify participants from the same device in friend matches and random matches.

Users can delete this information by deleting localStorage from their browser settings.

However, deleting it will remove past device identification information.

4. Use of Supabase

This service uses Supabase to provide online match features.

The following types of game data may be stored in Supabase.

  • Match room information
  • Random match queue information
  • Entered words
  • Scores
  • Match event history

This information is used only to the extent necessary to enable online matches.

5. Third-Party Provision

The operator will not sell or unnecessarily provide user information to third parties, except as required by law.

However, external services such as Supabase are used to the extent necessary to provide this service.

6. Data Retention Period

Match data and event history stored by this service may be retained for a certain period for service operation, operation checks, and issue investigation.

Old data that is no longer needed may be deleted or organized at the operator's discretion.

7. Data Deletion

If users wish to request deletion of their own data, please contact the operator-designated contact point.

However, because this service currently does not provide a login feature, it may not be possible to fully identify and delete all data for a specific user.

8. Security

The operator will endeavor to appropriately manage stored data.

However, this service is an experimental MVP and does not guarantee complete security.

9. Changes to the Privacy Policy

The operator may change this Policy as necessary.

The updated Policy becomes effective when posted on this service.

10. Contact

For inquiries regarding this Policy, please contact the operator-designated contact point.
