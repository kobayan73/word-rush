Word Rush 利用規約

1. サービス概要

Word Rush は、指定された条件に合う英単語を入力し、スコアを競う単語ゲームです。

本サービスでは、シングルプレイ、フレンドマッチ、ランダムマッチなどの機能を提供します。

本サービスはMVP段階の実験的なサービスであり、機能、仕様、デザイン、ルール、スコア計算方法などは予告なく変更される場合があります。

2. 利用条件

ユーザーは、本規約に同意したうえで本サービスを利用するものとします。

本サービスを利用した時点で、本規約に同意したものとみなします。

3. 禁止事項

ユーザーは、本サービスの利用にあたり、以下の行為を行ってはなりません。

  • スコア、対戦結果、ゲームデータを不正に改ざんする行為
  • 自動投稿、Bot、スクリプト等を用いた不正なプレイ
  • 大量アクセス、連続リクエストなど、サービスやデータベースに過度な負荷をかける行為
  • 他のユーザーのプレイを妨害する行為
  • 不正アクセス、リバースエンジニアリング、脆弱性の悪用
  • 法令または公序良俗に反する行為
  • その他、運営者が不適切と判断する行為

4. 対戦データ・スコアデータの取り扱い

本サービスでは、ゲーム進行、対戦同期、不正防止、サービス改善のために、以下のようなデータを保存する場合があります。

  • ランダムに生成される playerId
  • room id / room code
  • フレンドマッチ、ランダムマッチの部屋情報
  • 入力された単語
  • スコア
  • 対戦イベント履歴
  • 作成日時、更新日時

これらのデータは、ゲーム機能を提供するために利用されます。

5. サービスの変更・停止

運営者は、必要に応じて本サービスの全部または一部を変更、停止、終了することがあります。

これによりユーザーに損害が生じた場合でも、運営者は可能な範囲でのみ対応し、原則として責任を負いません。

6. 免責事項

本サービスはMVP段階の実験的サービスとして提供されます。

運営者は、本サービスの正確性、安定性、継続性、特定目的への適合性を保証しません。

通信環境、端末環境、ブラウザの仕様、外部サービスの障害等により、ゲームが正常に動作しない場合があります。

7. 利用規約の変更

運営者は、必要に応じて本規約を変更することがあります。

変更後の規約は、本サービス上に掲載された時点で効力を生じるものとします。

8. お問い合わせ

本サービスに関するお問い合わせは、運営者指定の連絡先までお願いいたします。

Word Rush プライバシーポリシー

1. 収集する情報

Word Rush では、ゲーム進行、対戦同期、不正防止、サービス改善のために、以下の情報を収集・保存する場合があります。

  • ランダムに生成される playerId
  • room id / room code
  • フレンドマッチ、ランダムマッチの部屋情報
  • 入力された単語
  • スコア
  • 対戦イベント履歴
  • 作成日時、更新日時
  • ブラウザの localStorage に保存される情報

現時点では、氏名、メールアドレス、ログイン情報など、個人を直接特定する情報は原則として収集していません。

2. 利用目的

収集した情報は、以下の目的で利用します。

  • ゲームの進行管理
  • フレンドマッチ、ランダムマッチの対戦同期
  • スコア表示、結果表示
  • 不正利用、スパム、改ざん行為の防止
  • サービスの改善、動作確認、不具合調査
  • 将来的な機能改善のための参考

3. localStorage の利用

本サービスでは、同じ端末を識別するため、ブラウザの localStorage にランダムな playerId を保存します。

保存される主な情報は以下です。

  • wordRushPlayerId

この playerId は、フレンドマッチやランダムマッチにおいて、同じ端末からの参加者を識別するために利用されます。

ユーザーは、ブラウザの設定から localStorage を削除することで、この情報を削除できます。

ただし、削除すると過去の端末識別情報は失われます。

4. Supabase の利用

本サービスでは、オンライン対戦機能を提供するために Supabase を利用しています。

Supabase には、以下のようなゲームデータが保存される場合があります。

  • 対戦ルーム情報
  • ランダムマッチ待機情報
  • 入力単語
  • スコア
  • 対戦イベント履歴

これらの情報は、オンライン対戦を成立させるために必要な範囲で利用されます。

5. 第三者提供

運営者は、法令に基づく場合を除き、ユーザーの情報を第三者に販売または不必要に提供することはありません。

ただし、本サービスの提供に必要な範囲で、Supabase などの外部サービスを利用します。

6. データの保存期間

本サービスで保存される対戦データやイベント履歴は、サービス運営、動作確認、不具合調査のために一定期間保存される場合があります。

不要になった古いデータは、運営者の判断により削除または整理されることがあります。

7. データ削除について

ユーザーが自身のデータ削除を希望する場合は、運営者指定の連絡先までお問い合わせください。

ただし、現時点ではログイン機能を提供していないため、特定ユーザーの全データを完全に識別・削除できない場合があります。

8. セキュリティ

運営者は、保存されるデータについて、適切な管理に努めます。

ただし、本サービスはMVP段階の実験的サービスであり、完全な安全性を保証するものではありません。

9. プライバシーポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。

変更後のポリシーは、本サービス上に掲載された時点で効力を生じるものとします。

10. お問い合わせ

本ポリシーに関するお問い合わせは、運営者指定の連絡先までお願いいたします。
